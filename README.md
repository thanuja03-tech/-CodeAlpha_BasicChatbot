Chatbot

A simple text-based chatbot developed using Python. The chatbot interacts with users by responding to predefined questions and messages.

Features

* User-friendly conversation interface
* Responds to basic greetings and questions
* Uses if-else conditions for responses
* Easy to understand and modify

Technologies Used

* Python

How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Run the Python file:
    python chatbot.py
4. Start chatting with the bot.

Example

User: Hello
Bot: Hi! How can I help you today?

User: How are you?
Bot: I’m doing great! Thanks for asking.
